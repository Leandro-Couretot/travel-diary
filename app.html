¿Cómo usar la app?
🗂 Tus álbumes
▸Cada álbum agrupa los recuerdos que quieras. Tocá Nuevo álbum para crear uno.
▸Tocá la tarjeta de un álbum para entrar al diario.
▸Tocá ↗ para compartir el álbum. Tocá ▶ para el slideshow.
⬆ Carga masiva
▸Tocá ⬆ para subir muchas fotos a la vez. La app las agrupa por día automáticamente.
📅 El diario
▸Navegá entre días con las flechas o tocando la fecha.
▸Tabs: Día para editar, Mes para el calendario, Galería para buscar una foto puntual, Libro para el fotolibro.
▸Tocá una foto para verla en pantalla completa. Arrastrá el ícono ⠿ para reordenar.
Acordate de tocar Guardar día antes de cambiar de día.
🎙 Grabar audio
▸Tocá el micrófono para grabar. Tocá ⏹ para detener y guardar.
Plan gratis: hasta 4 audios en la cuenta (subidos o grabados). Borrá alguno para agregar otro, o pasate a Pro para no tener límite.
📖 Fotolibro
▸Se ve como varias páginas en miniatura, cada una con la proporción real de la hoja — arrastrá el ⠿ de una página para cambiarla de lugar, tocá el + entre páginas para agregar una ahí, o movés fotos entre páginas / al "sin ubicar".
▸El menú ··· del header suma Tamaño de hoja, Agregar página y Recrear libro (rearma todo al azar) — y un toggle para mostrar/ocultar la fecha y el texto de cada foto.
▸El ícono ⛶ de cada foto abre un editor para encuadrarla — movela y acercala (pellizcar o la rueda del mouse) para elegir qué parte se ve, se aplica igual en pantalla y en el PDF.
▸Exportar genera un PDF listo para imprimir, con el sangrado que elijas — avisa (sin bloquear) si alguna foto queda con poca resolución para su tamaño (encuadrar con mucho zoom también puede bajarla).
Plan gratis: 1 PDF por mes calendario. Se resetea el día 1, o pasate a Pro para exportar sin límite.
